VS Mobile

Редактор кода для Android в стиле VS Code, написан на Kotlin + Jetpack Compose.

Версия: v1.0 release

Возможности
Создание проектов, папок и файлов, дерево файлов с перетаскиванием
Вкладки открытых файлов и индикатор несохранённых изменений
Подсветка синтаксиса: Kotlin, Java, Python, JS/TS, C/C++, XML/JSON и др.
Панель спецсимволов для набора кода на экранной клавиатуре
Запуск Python-скриптов в приложении, включая ввод через input()
ИИ-помощник с собственным API-ключом нейросети
Тёмные темы и выбор цвета акцента
Все файлы остаются на устройстве, разрешения на хранилище не нужны
Сборка
Откройте папку app в Android Studio (Giraffe/Koala или новее). Если папка app вынесена отдельно, откройте её как модуль нового проекта или добавьте недостающие build.gradle.kts и settings.gradle.kts из корня.
Дождитесь синхронизации Gradle.
Нажмите Run ▶.

Минимальная версия Android: 7.0 (API 24).

Статус
Вход в аккаунт и оплата подписки пока недоступны.
ИИ-помощник работает через собственный API-ключ, который задаётся в настройках.
